# Code

This folder contains the Jupyter notebook used for the statistical and natural language processing analyses reported in the dissertation.

The main analysis notebook includes:

- Data preprocessing
- Descriptive analysis
- Kruskal–Wallis tests
- Dunn's post-hoc tests
- Multiple-testing correction
- LDA topic modelling
- Sentence-BERT and K-Means clustering
- Chi-square analysis
- NLP robustness and sensitivity analyses
